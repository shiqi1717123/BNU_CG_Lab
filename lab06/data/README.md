# Lab06 Data

This directory stores the target cow model and its texture files.

Required files for the notebook:

```text
cow.obj
cow.mtl
cow_texture.png
```

`cow.obj` references `cow.mtl`, and `cow.mtl` references `cow_texture.png` through `map_Kd`.

`cow.glb` is the original textured glTF binary container and is kept as source material.
