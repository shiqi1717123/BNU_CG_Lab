## 实验概述

本实验使用Taichi GGUI实现一个实时3D质点弹簧布料系统。基础部分完成了20x20布料网格、结构弹簧、重力、阻尼、速度钳制，以及显式欧拉、半隐式欧拉和隐式欧拉三种积分方法。选做部分继续加入了剪切弹簧、弯曲弹簧和球体碰撞，用来观察布料抗剪切、抗弯曲和空间碰撞后的形态变化。

基础部分包含了以下内容：

- 初始化布料质点位置、速度、受力、固定点和结构弹簧拓扑。
- 使用 `@ti.func` 实现力计算和速度钳制，并内联到积分 kernel 中。
- 使用 `ti.atomic_add` 累加弹簧两端质点的受力，避免并行写入冲突。
- 实现显式欧拉、半隐式欧拉、隐式欧拉三个积分 kernel。
- 使用GGUI控制面板实时切换积分方法、暂停和重置模拟。

选做部分包含以下内容：

- 剪切弹簧：连接网格对角线质点，增强布料抗斜向变形能力。
- 弯曲弹簧：连接间隔一个网格点的质点，增强布料抗折叠能力。
- 球体碰撞：将进入球体内部的质点投影回球面外侧，并处理速度分量。

## 交互说明

基础版和选做版的交互界面选项belike

- `Explicit Euler`：显式欧拉。先用旧速度更新位置，再用旧受力更新速度，稳定性最差。
- `Semi-Implicit Euler`：半隐式欧拉。先更新速度，再用新速度更新位置，稳定性较好。
- `Implicit Euler`：隐式欧拉。使用未来状态计算受力，本实验用定点迭代近似求解。
- `Pause Simulation` / `Resume Simulation`：暂停或继续模拟。
- `Reset Cloth`：重置布料状态。
- `dt`：单个物理子步时间。
- `substeps`：每帧执行的物理子步数量。
- `k_s`：弹簧劲度系数。
- `k_d`：阻尼系数，可设置为 `1.0`、`5.0` 对比阻尼效果。
- `max velocity`：速度钳制上限，用来缓解显式欧拉中的数值爆炸。

选做版还额外提供：

- `Shear springs`：开关剪切弹簧。
- `Bending springs`：开关弯曲弹簧。
- `Sphere collision`：开关球体碰撞。
- `Render all springs`：显示全部结构、剪切、弯曲弹簧。默认关闭，只显示结构网格。
- `collision margin`：碰撞外扩厚度。默认值为 `0.05`。
- `Springs`：显示当前弹簧数量。结构弹簧为 `760` 条，加入剪切弹簧后为 `1482` 条，再加入弯曲弹簧后为 `2202` 条。

鼠标右键拖动并配合 `WASD/QE` 可以移动 GGUI 摄像机。

## 场景与模型

布料由 `20 x 20` 个质点组成，初始放置在水平的 XZ 平面上，高度为 `y = 0.8`。第一排左右两个角点固定，用来模拟布料被悬挂后的下垂效果。

基础版只使用结构弹簧：

- 横向结构弹簧：连接 `(i, j)` 与 `(i + 1, j)`。
- 纵向结构弹簧：连接 `(i, j)` 与 `(i, j + 1)`。

选做版继续加入：

- 剪切弹簧：连接 `(i, j)` 与 `(i + 1, j + 1)`、`(i + 1, j - 1)`，防止网格斜向塌陷。
- 弯曲弹簧：连接 `(i, j)` 与 `(i + 2, j)`、`(i, j + 2)`，减弱尖锐折叠。
- 球体：位于 `(0.0, 0.35, 0.0)`，半径为 `0.28`，用于演示空间碰撞。

## 实现要点

### 1. GPU 同步式初始化

初始化拆分为多个 kernel：

- `init_positions()`：初始化位置、速度、受力和固定点。
- `init_springs()`：初始化弹簧端点、原长和刚度比例。
- `init_spring_indices()`：同步渲染用线框索引。

Python 侧按顺序调用这些 kernel，保证前一个 kernel 的写入在后一个 kernel 使用前已经完成。

### 2. 力学计算

每个质点受到重力和阻尼力：

```math
f_d = -k_d v
```

每条弹簧按照胡克定律计算弹力：

```math
f_a = -k_s (|x_a - x_b| - l) \frac{x_a - x_b}{|x_a - x_b|}
```

由于多条弹簧可能同时向同一个质点累加力，程序使用 `ti.atomic_add` 保证并行写入安全。

### 3. 三种积分方法

显式欧拉：

```math
x_{t+1} = x_t + v_t \Delta t
```

```math
v_{t+1} = v_t + a_t \Delta t
```

半隐式欧拉：

```math
v_{t+1} = v_t + a_t \Delta t
```

```math
x_{t+1} = x_t + v_{t+1} \Delta t
```

隐式欧拉使用 `x_next`、`v_next`、`f_next` 作为未来状态缓存，并进行 3 次定点迭代近似求解。

### 4. 球体碰撞

选做版使用连续点-球碰撞检测：不仅检查质点更新后的终点是否在球内，也检查质点从上一位置到新位置的运动线段是否穿过球体。发生碰撞后，质点会被投影到外扩后的球面上，并移除朝向球体内部的速度分量。

这里的碰撞对象仍然是质点，而不是完整三角面片。因此渲染线段或想象中的布料面仍可能出现轻微视觉穿模。`collision margin` 用于给质点碰撞半径外扩一层可视厚度，减轻这种现象。

## 现象分析

### 1. 积分方法稳定性

显式欧拉完全使用旧状态推进，在弹簧刚度较高、时间步较大时容易发散。半隐式欧拉先更新速度再更新位置，通常比显式欧拉稳定。隐式欧拉用未来状态估计受力，数值上更稳定，但因为本实验使用的是定点迭代近似，过大的时间步仍然可能产生形变误差。

### 2. 剪切弹簧与弯曲弹簧

只有结构弹簧时，布料网格容易被拉成菱形，整体比较软。加入剪切弹簧后，网格对角线也会抵抗拉伸，所以布料更不容易发生斜向塌陷。加入弯曲弹簧后，相隔两个网格点的质点也会互相约束，布料会显得更厚、更有抗弯曲能力。

## 实验总结

本实验把布料模拟拆成“拓扑初始化、受力累加、积分推进、交互渲染”几个阶段。结构弹簧可以保持基本网格形状，剪切弹簧和弯曲弹簧进一步改善布料形态。三种积分方法的对比也能直观看到数值稳定性差异：显式欧拉更容易发散，半隐式欧拉更适合实时模拟，隐式欧拉更稳定但实现和计算成本更高。球体碰撞部分展示了基于位置投影的简单碰撞处理，同时也暴露出点级碰撞与真实面级碰撞之间的差距。
